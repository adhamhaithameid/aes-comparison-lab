    Implementation Profiles

    Scratch C++

    Educational
    • Approach: Byte-oriented, table-driven S-box
    • Transformations: SubBytes, ShiftRows, MixColumns, AddRoundKey
    • Key Schedule: On-the-fly expansion
    • Mode: ECB (single block)
    • Authentication: None
    • Hardware Accel: No AES-NI
    • Use Case: Learning, reference implementation

    OpenSSL ECB

    Production
    • Approach: Optimized assembly + AES-NI
    • Transformations: Same AES rounds
    • Key Schedule: Pre-computed round keys
    • Mode: ECB (Electronic Codebook)
    • Authentication: None
    • Hardware Accel: AES-NI, AVX-512
    • Use Case: Legacy compatibility

    OpenSSL GCM

    Recommended
    • Approach: Optimized assembly + AES-NI + PCLMUL
    • Transformations: AES-CTR + GHASH
    • Key Schedule: Pre-computed round keys
    • Mode: GCM (Galois/Counter Mode)
    • Authentication: Built-in (128-bit tag)
    • Hardware Accel: AES-NI, PCLMULQDQ
    • Use Case: TLS 1.3, modern applications
