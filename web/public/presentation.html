What is AES?

  • Symmetric block cipher — FIPS 197 (NIST, 2001). 128-bit blocks.
  • Keys: 128 / 192 / 256 bits. AES-128 uses 10 rounds.
  • Rounds: SubBytes → ShiftRows → MixColumns → AddRoundKey.
  • Raw AES gives confidentiality only — no integrity, no authentication.
  • Real systems need a mode of operation (GCM, CBC, CTR) + authentication.
Rule of thumb: learn with A, ship with B (or libsodium/mbedTLS).

Implementation A — Scratch AES-128 Impl A

What it is

  • Written from scratch in C++17 (src/aes_core.hpp/.cpp).
  • Every transform exposed for learning & validation.
  • Raw block cipher — encrypts 16-byte blocks.

Provides

  • FIPS 197 KATs pass.
  • NIST CAVP ECB KATs (GFSbox, VarTxt, VarKey, MMT).
  • Cross-validation vs OpenSSL on 1000 random blocks.
  • CLI: aes_scratch kat / encrypt-block / roundtrace.
⚠ Warning: No authentication, no replay protection, no padding — education/validation only.

Implementation B — OpenSSL AES-128-GCM Impl B

What it is

  • Wrapper around OpenSSL EVP (src/aes_gcm_openssl.hpp/.cpp).
  • Authenticated encryption: confidentiality + integrity.
  • Hardware-accelerated (AES-NI / ARMv8 crypto).

Provides

  • Fresh random 96-bit nonce per encryption.
  • 128-bit auth tag verified before plaintext release.
  • File encryption CLI: aes_openssl keygen / encrypt / decrypt / selftest.
  • NIST CAVP GCM KATs incl. official FAIL cases.
✅ Recommended for real applications (or libsodium/mbedTLS).

Usage — CLI

./build/aes_scratch encrypt-block --key 000102030405060708090a0b0c0d0e0f \\
    --input 00112233445566778899aabbccddeeff

Implementation B (file encryption)

./build/aes_openssl keygen mykey.txt
./build/aes_openssl encrypt mykey.txt secret.txt secret.enc
./build/aes_openssl decrypt mykey.txt secret.enc secret_dec.txt

Security model

Impl A risks

  • Ciphertext tampering undetected.
  • Replay attacks possible.
  • ECB-style misuse if chained naively.
  • No padding → must handle multiples of 16 B.

Impl B guarantees

  • Confidentiality + integrity (GCM).
  • Tag verified before plaintext release.
  • Nonce uniqueness enforced by design.
  • Hardware-accelerated.
Rule of thumb: learn with A, ship with B (or libsodium/mbedTLS).
