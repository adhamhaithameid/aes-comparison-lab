    AES Best Practices

    How to use AES correctly in real systems.

    • Use an authenticated mode. Prefer AES-GCM or AES-CCM. Never use ECB. CBC/CTR alone provide no integrity.
    • Never reuse a nonce. In GCM, reusing a nonce with the same key breaks confidentiality and authenticity.
    • Use a CSPRNG for keys and nonces. Never derive keys from passwords without a KDF (Argon2/scrypt/PBKDF2).
    • Use a 96-bit (12-byte) nonce for GCM. Avoid 64-bit nonces unless you know why.
    • Verify the tag before releasing plaintext. Use constant-time comparison.
    • Don't implement crypto yourself. Use OpenSSL, libsodium, or Web Crypto API in production.
    • Rotate keys periodically. Plan key lifecycle and revocation.
    • Don't log keys or plaintext. Keep secrets out of logs and error messages.
